# Contributing

1. Create a focused branch.
2. Keep NASA source policy and attribution visible.
3. Add a fixture and regression test for every adapter change.
4. Do not add API keys, analytics, trackers, or copied NASA media files.
5. Run `npm test` and `npm run build` before opening a pull request.

Pull requests should explain the scientific claim, source, browser policy, performance cost, accessibility impact, and verification performed.
