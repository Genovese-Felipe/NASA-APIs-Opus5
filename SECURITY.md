# Security and privacy

## Reporting

Please report security concerns privately through the repository owner’s GitHub security contact rather than a public issue.

## Data handling

- No account, analytics, advertising, or telemetry service is present.
- A personal NASA key is stored only in browser `sessionStorage`.
- API responses may be cached locally to reduce rate-limit pressure.
- Source strings are inserted as text, never executed as HTML.
- External links use `noopener noreferrer`.

Do not commit real API keys. Git history is public even after a later deletion.
