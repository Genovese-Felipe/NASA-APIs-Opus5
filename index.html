Rendering notes

The canvas computes a camera ray per pixel and intersects a procedural celestial sphere in WebGL2. It is a visual instrument, not a scientific ephemeris or a replacement for mission analysis. The live values come from NASA APIs and are marked when the app is using its resilient demonstration dataset.

Keyboard flight deck

  • W A S D / arrow keys — rotate viewpoint
  • Space — toggle orbit mode
  • + / − — zoom
  • R — reset viewpoint
  • M — ambient sonification
  • 1–4 — switch scenes
